QuickNotes

QuickNotes is a simple note-taking web application that allows users to create, organize, search, and delete notes. Notes can be assigned to Personal, Work, or Study categories, and they are stored in the browser so they remain available after refreshing the page.

Features

- Add notes with Personal, Work, or Study categories
- Validate empty notes
- Limit notes to 200 characters
- Delete individual notes
- Display the number of saved notes
- Search notes as you type
- Case-insensitive note search
- Save notes using localStorage
- Responsive design for smaller screens
- Display the date and time each note was created

How to Run the Project Locally

1. Clone or download the repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Start adding and managing your notes.
